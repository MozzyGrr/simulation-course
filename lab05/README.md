#### Часть 1 

Теория:
α ~ U[0,1), то есть равномерное распределение.
В коде alpha = random.random()

Самое главное, для вычисления вероятности попадания в участок, это P(α < p) = p. 
Вероятности Да/нет p = 0.5


#### Часть 2

Теория:
Интервал [0,1) разбивается на отрезки, где длина каждого отрезка равна некоторому событию A. Сумма всех событий будет равна 1. 
Используя этот принцип, мы создаем наш "Шар предсказаний". 
Задаем всем возможным событиям равную вероятность, сумма всех событий = 1. Далее делаем

        for name, p in self.events:
            cumulative += p
            if alpha < cumulative:
                return name
p - вероятность события.
cumulative - сумма вероятностей прошедших событий. Если α < cumulative - значит событие наступило.
